SMART-GATE (Web-Host) - SB-SGATE-UN

Smart Gate is your intelligent Home Gateway device interfacing to the G4 SBUS controllers and allow you to control your devices in your home from your Laptop, Mobile or any device having a browser. You can chat with the Smart Gateway to know the status of your home devices. The Smart Gateway will keep track of your calendar and inform you of your upcoming events on your calendar.


Control Compatibility:

• Lighting
• Climate
• Music
• Curtains
• Moods
• Media
• Security
• Service
• Drapes
• Pumps
• Gates

Features


• ZigBee (ZigBee Pro) Home Automation Support (includes Physical interface)
• Ethernet Support (includes Physical interface)
• Bluetooth 2.0 (includes Physical interface)
• G-4 Smart-Bus support (library interface) over UDP
• Secured Communication over SSL
• Gateway Image upgrade locally through USB
• SD Card interface for log storage
• Back up and Restore all the S-Bus config data
• DDNS Support for remote access of gateway
• Integrated Web server
• Mobile phone Calendar Synchronization with gateway with support for 4 phones
• Chat based support to control home devices
• Support for Community Features - Provision to select the service provider such as Carpenter,
Plumber, Electrician etc.. and Send a service request to the provider via email
• Web Whether feed from 4 different news providers(Configurable)
• Photo viewer functionality
• Multiple Access Control – Admin User, Power User and Normal User
• Browsers Supported – IE8 , Safari 4, FireFox
