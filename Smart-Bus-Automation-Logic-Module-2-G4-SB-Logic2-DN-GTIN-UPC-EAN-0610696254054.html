Smart-Bus Automation Logic Module 2 (G4) - SB-Logic2-DN

Description

DIN-Rail Mount, Central Time Clock and Main Automation Controller. It is the smart system servant that assist and monitor temperature, events, energy consumption, patterns, with main Targets: maintain, safeguard, protect and economize. It Can Trigger prayer announcements, reminders, alerts, macros, and moods. Each Logic module Consist of 240 tables, Each Table of 4 programmable Logic Lines totaling up to 960 Line of Logics using simplified (and, Or Nand, Nor, with 255 Flags). logical condition consist of trigger combinations like: time, scene Light channel status, curtain status, room temperature, security mode, day night, time... and so on

**Added function: Improved Logic Table Configuration and Viewing of used against available flags.
